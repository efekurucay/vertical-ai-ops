# Contributing to vertical-ai-ops

Thank you for your interest in contributing! This repo is a community-maintained playbook for vertical-specific AI validation layer opportunities.

## How to Add a New Vertical

1. **Copy `template.md`** to the appropriate sector folder (e.g., `finans/yeni-firsat.md`)
2. **Fill in all sections** — don't leave placeholders
3. **Be specific**: name the actual regulation, standard, or protocol that creates the validation need
4. **Include a Turkey-specific section** where applicable — local market context is a core value-add of this repo
5. **Open a Pull Request** with the title: `feat: [sector] — [opportunity name]`

## Folder Naming Conventions

- Use lowercase Turkish (no special characters in folder names): `saglik`, `finans`, `hukuk`
- File names: `kebab-case.md`

## Quality Bar

Every file should answer: *"If someone wanted to build this tomorrow, what would they need to know?"*

- Real regulation/standard names (not vague references)
- Realistic tech stack
- Honest assessment of difficulty and market size
- No hype, no vague claims
